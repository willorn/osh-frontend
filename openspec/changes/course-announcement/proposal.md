# Proposal: course-announcement

## 背景

后端已为课程模块接入公告能力（系统通知 + 课程动态），前端课程列表页需要对齐工具模块，展示双栏滚动公告并支持 WebSocket 实时刷新。

## 目标

- 课程列表页展示「系统通知」「课程动态」双栏公告。
- 新增课程公告 API 封装。
- WebSocket 支持 `COURSE_USER_NOTICE_REFRESH` 触发公告刷新。
- 无数据时显示占位文案，不影响页面其他功能。

## 非目标

- 本次不改造工具模块公告 UI。
- 本次不新增全局公告组件（仅课程页内实现）。
- 本次不改动课程详情、支付页。

## 用户影响

- 访问 `/course/*` 列表页可看到公告双栏。
- 有新审核/购课动态时，课程动态栏自动刷新。
- 其他页面与接口不受影响。

## 风险

- 兼容性风险：低。纯增量 UI 与 API 调用。
- 数据风险：无。
- 性能风险：低。页面 mount 时各请求一次公告接口。
- 安全风险：低。复用现有 token headers。
- 回滚风险：revert commit 即可。

## 验收标准

- [ ] 课程列表页展示系统通知、课程动态双栏。
- [ ] 无数据时显示「暂无系统通知 / 暂无课程动态」。
- [ ] 收到 `COURSE_USER_NOTICE_REFRESH` 后自动刷新公告。
- [ ] 不影响课程搜索、收藏、分页等现有功能。
