# 前端测试规范

## 最低验证

每个 PR 至少说明运行过什么验证。

推荐基础命令：

```bash
npm run generate
```

## 页面 smoke

涉及页面变更时，至少验证：

- 页面能打开。
- 接口请求路径正确。
- loading/empty/error 状态正常。
- 登录态跳转正常。
- 移动端和桌面端不明显错位。

## 核心业务回归

- 登录/注册。
- 课程列表/详情/小节。
- 支付/订单。
- 工具使用。
- 反馈/问答。
- 用户中心。

## AI 视觉验证

大面积 UI 调整后，Codex 应使用浏览器打开本地页面检查，不只看代码。
