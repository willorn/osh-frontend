# 前端代码风格

## Vue/Nuxt

- 页面文件保持页面编排，不塞复杂接口逻辑。
- 组件命名表达业务含义。
- props 和 emits 要清楚。
- 可复用逻辑放 composables。
- 不在多个页面复制同一段请求逻辑。

## 样式

- 样式调整不得影响业务状态。
- 响应式必须兼容移动端和桌面端。
- 不要用大面积单一色系覆盖整个站点。
- 组件内文字不得溢出按钮、卡片和弹窗。

## API

- 请求路径统一从 composables 封装。
- 不在页面里散写 `$fetch('/api/...')`。
- 错误提示统一。
- 登录失效统一处理。

## 权限

- 需要登录的页面必须配置 middleware。
- 只允许游客访问的页面使用 `only-visitor` 逻辑。
- VIP、小班、课程权益逻辑要和后端接口语义对齐。
